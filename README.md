# OpsMind · 运维知识库智能问答系统

面向运维团队的知识沉淀与智能问答系统：问题上报 → AI 自动归类脱敏 → 管理员审核入库 → 知识库语义检索问答，形成知识闭环。支持网页门户访问，双角色（管理运维人员 / 使用人员）RBAC 权限隔离。

## 功能模块

- **登录与权限**：WorkBuddy 账号免密登录；首位登录者自动成为管理员；`profiles` 表 + 数据库 RLS 策略强制角色隔离
- **智能问答**：提问限 100 字 → 本地相似度召回 Top 10（不走大模型，控费）→ 大模型语义打分，按 0.85 阈值过滤取 Top 3-5；命中展示来源/适用环境/更新时间；未命中由 AI 生成通用排查思路并可一键上报（自动携带思路）
- **知识库管理**：按关键字/产品/模块/分类/状态检索；条目分「故障案例」与「常识知识」两类；管理员可新增、编辑、删除、查看详情
- **批量导入 / 导出**：下载 Excel 模板、上传批量录入（逐行校验、自动脱敏、标题查重）
- **AI 智能入库**：粘贴产品资料/FAQ/处理步骤，AI 自动拆分为多条结构化条目（可编辑、可勾选），确认后入库；支持选择整理模型
- **上报与审核**：上报单初始「待审核」→ 管理员通过/驳回/修改 → 通过后自动发布入库；重复问题提示合并；上报人可查看处理状态
- **审计与控费**：所有增删改查与审核写入操作日志；按接口维度统计大模型 Token 用量

## 目录结构

```
index.html            单页应用入口
css/style.css         样式
js/config.js          云服务连接配置（endpoint / publishableKey）
js/cloud.js           云 SDK 初始化封装
js/api.js             数据访问层（知识条目、审核、日志、用户）
js/similarity.js      本地字符级相似度召回
js/llm.js             大模型能力封装（归类脱敏 / 语义打分 / 排查思路 / 资料整理）
js/app.js             视图与交互逻辑（路由、页面渲染、表单校验、导入导出）
```

## 运行与部署

1. 云服务：需在 WorkBuddy 内为应用开通云服务，将 `endpoint` 与 `publishableKey` 填入 `js/config.js`
2. 数据库：执行 `database/init.sql` 建表（4 张表 + 函数 + RLS 策略），可选执行 `database/seed-sample.sql` 导入示例数据
3. 第三方库：`js/vendor/` 下的云 SDK 与 SheetJS 需自行放置（版权归各自所有者，不入库）
4. 发布：以静态站点方式发布即可，无需构建步骤

## 说明

- 大模型调用经云服务免密钥通道，请求参数精简以保证通道兼容性；含首结果 20 秒 / 流空闲 30 秒双看门狗与自动重试、内容抢救
- 入库前自动脱敏：IP 掩码、账号/密码/密钥/Token 替换为 `***`
- `publishableKey` 为可公开密钥（权限受行级安全策略约束），请勿在仓库中存放任何私密密钥或真实业务数据
